# SKB 機櫃裝機模擬器

把器材放進 SKB 機架箱，用 3D 看裝不裝得下，並比較哪一台箱子最合適。

線上版：https://bbshen1995-hash.github.io/skb-rack-planner/

- 收錄 SKB 在售的 41 款機架箱、53 件常見器材（混音器、IEM 發射機、機架電源、XLR 分接盤等）
- 依官方尺寸換算前後淨空，判定 U 數、機身深度與前後對打
- 同一套器材丟進每個機櫃比較，第一列就是「裝得下的最小箱」
- 單一 HTML，下載後雙擊即可離線使用

數字來源：SKB 官網規格、原廠 PDF 與經銷商規格頁。標「推算」的前後淨空是用內部深度減軌到軌深度再對半分；標「推論值」的器材深度原廠未公布。接頭插上線材後往後凸出的長度，規格表都不列，工具沒有算進去，前後對打請自己再留 40 至 60 mm。
